# Face-Mask-Detection-
I developed a Face Mask Detection system as a mini project to identify whether a person is wearing a face mask or not using computer vision and deep learning techniques.
The project uses a Convolutional Neural Network (CNN) trained on labeled image data to classify faces into “Mask” and “No Mask” categories. Real-time face detection was implemented using OpenCV, enabling the system to work efficiently on live camera input.
